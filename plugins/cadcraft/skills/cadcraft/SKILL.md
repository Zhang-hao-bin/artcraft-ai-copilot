# CADCraft 绘图

此插件连接本机 CADCraft 桌面窗口的 `127.0.0.1:7981` 控制端口。坐标采用绘图单位，Y 轴向上。明确用户需要的单位，结合当前图纸单位处理数值；不要默认每张图纸都是毫米。

## 获取图纸与操作

- 用 `inspect_drawing` 确认活动图纸、实体数量、未保存状态；用 `query_entities` 获取准确几何数据。用户问屏幕上的图形时，可配合 `screenshot` 或 `ui_inspect` 查看当前窗口。
- 优先用几何数据回答尺寸问题。截图适合检查可见布局，不能代替精确实体坐标。
- 简单绘图使用 `command_line`，例如 `rectang 0,0 100,60`。需要结构化操作时，用 `list_commands` 查询当前版本的命令参数，再调用 `execute`。
- 绘图修改按顺序执行，留意命令是否仍在等待输入；需要退出未完成命令时用 `cancel`。
- 保留与任务无关的实体。切换、打开或新建图纸前检查未保存内容，避免丢失用户工作。
- 尺寸标注使用真正的 Dimension 实体；不要用普通文字冒充尺寸标注。根据已知坐标选择标注端点和位置。
- 修改后核对实体几何，并用 `render` 或 `screenshot` 检查显示效果。按用户指定位置保存；没有指定时，为新文件选择易识别的名称，避免覆盖已有文件。

## 连接与可见性

优先启动已安装的 `artcraft-cadcraft`，它开启 7981 控制端口并提供原生 Codex 侧边栏。连接失败时先检查该端口和应用进程；若用户已有 CADCraft 窗口，保留其中未保存图纸，避免直接结束进程。此插件采用桌面桥接，不要为了绕过连接错误切换成无界面的另一张图纸。

`screenshot` 返回截图路径时，可用可用的图片查看工具读取该路径。每次截图只代表采样时刻；不能声称插件会持续实时监视整个桌面。
