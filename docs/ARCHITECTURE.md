# 实现与状态管理

参考实现是 CADCraft 的原生 Rust/egui 侧栏，不是浏览器覆盖窗口。MCP 服务让外部 agent 调用软件命令；侧栏通过 Codex app-server 的动态工具回调复用同一引擎。

源码补丁中：

- `copilot.rs` 处理子进程、JSON 行请求 ID、初始化、分页模型目录、thread/turn、增量消息、工具回调、输入框与可选视图。
- `copilot_documents.rs` 根据稳定 DocState UID 管理各文档及其多段会话，按保存路径恢复有界历史。
- `lib.rs` 在命令、轮询和 UI 渲染前后同步文档所属状态，保存配置并提供重开入口。
- `menus.rs` 声明 `ui.copilot.*` 命令，UI 和程序化控制走同一入口。

每段会话保存独立消息、草稿、模型/思考强度、视图选项、最近实体和运行连接。新文件不继承旧聊天；新对话不会调用 reset 清空历史；切换会话可以回到原 thread。

停止或切换时取消旧工作，工具执行检查 busy、stopping、turn 和目标文档。后台实体完成只更新原有结果，过期任务不自动打开窗口。本地恢复记录不会持久化 busy、待调用工具或进程 PID；线程重建时附带有限历史。

当前已保存文件以规范化路径匹配：最多 64 个文件、总计 8 MiB，每个文件最多 64 段会话；每段保存最近 100 条消息（单条最多 16000 字节）。这是近期历史机制，不是无限归档。新建未保存文件只在本次窗口中隔离，未实现跨重启的未保存文档恢复项目。

模型和强度来自当前 Codex 目录，发送时显式传所选设置，恢复默认也要覆写旧选择。图片能力不支持时停用附图。文本、对象属性与图像属于不可信数据，不作为开发者指令。

CADCraft 新版引入自己的停靠面板和更多配置，升级补丁保留它们。几个上游鼠标测试改用实际画布位置/范围以适配额外侧栏，原有几何与行为断言仍保留；文件名展示加上上下文并截断，避免窄面板溢出。

公开版采用独立应用身份 `io.github.artcraft-copilot.cadcraft`，复用用户自己的 Codex 审批策略，不复制原个人环境的 never 策略。
