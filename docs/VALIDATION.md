# 验证记录与范围

## 源实现（2026-10-15）

CADCraft v0.7.0 + Copilot 候选在 Linux/Rust 1.95 环境通过：格式、修改模块 Clippy、289 项 UI 测试、WebAssembly 编译、桌面构建。测试覆盖文档隔离、会话新增/切换、草稿与产物保留、旧格式恢复、取消、收起后重开、实际 egui 点击与软件命令。

独立设置目录的实际窗口验证了 MCP、模型目录、两段不同 thread 及切回恢复，没有发送模型消息或读取个人聊天。可选实体后端在此前实际验证过轴承、长方体、圆柱和球体，含有效性、闭合性、正体积以及 STEP 回读检查。

## 公开封装版（2026-10-17）

公开封装对源实现做的变化：移除机器路径与个人 marketplace 名称，采用独立应用身份，继承 Codex 审批设置，增加可复现构建与全新前缀安装工具，并把 FreeCAD 路径/输出目录改为可配置。具体最终运行结果记录在 `validation-summary.json`。

辅助测试使用临时 Git 仓库和安装前缀，验证补丁快照不改变原索引、源码修改检测、构建失败不安装、运行窗口锁、产物哈希、备份与回退不覆盖更新后的设置，以及稳定标签发现、真实 clone/fetch/三方合并和冲突停止。

## 尚未证明

未在每款 ArtCraft 相关软件或每种操作系统中实现同等侧栏；未验证所有 agent 的配置格式；普通 MCP JSON 不强制只读；外部只读摘要不一定暴露稳定文档 UID。图片采样不是实时屏幕监视。不能把语义评估、模板生成或工具枚举描述成完整的写操作验收。

不发布个人原始运行日志、聊天、图纸、账号、系统配置和大二进制。公开验证只保留命令、计数和不含个人数据的摘要。
