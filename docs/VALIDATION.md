# 验证记录与范围

## 源实现（2026-10-15）

CADCraft v0.7.0 + Copilot 候选在 Linux/Rust 1.95 环境通过：格式、修改模块 Clippy、289 项 UI 测试、WebAssembly 编译、桌面构建。测试覆盖文档隔离、会话新增/切换、草稿与产物保留、旧格式恢复、取消、收起后重开、实际 egui 点击与软件命令。

独立设置目录的实际窗口验证了 MCP、模型目录、两段不同 thread 及切回恢复，没有发送模型消息或读取个人聊天。可选实体后端在此前实际验证过轴承、长方体、圆柱和球体，含有效性、闭合性、正体积以及 STEP 回读检查。

## 公开封装版（2026-10-17）

公开封装对源实现做的变化：移除机器路径与个人 marketplace 名称，采用独立应用身份，继承 Codex 审批设置，增加可复现构建与全新前缀安装工具，并把 FreeCAD 路径/输出目录改为可配置。具体最终运行结果记录在 `validation-summary.json`。

辅助测试使用临时 Git 仓库和安装前缀，验证补丁快照不改变原索引、源码修改检测、构建失败不安装、运行窗口锁、产物哈希、备份与回退不覆盖更新后的设置，以及稳定标签发现、真实 clone/fetch/三方合并和冲突停止。

## 跨 agent skill 精改（2026-10-17）

新增 agent 通用路由、制作 agent/接收客户端/侧栏运行时的边界、Cursor/Claude Code 项目布局、中性 stdio 包、根目录可复制提示词，以及 `package_agent.py`。Cursor 与 Claude Code 的配置/技能位置对照各自官方文档核对，链接在适配参考中。

本次未修改 CADCraft Rust 补丁，因此沿用上方构建证据，未将旧的 289 项 UI 测试冒充跨客户端验收。新增 5 项 Python 打包行为测试，加上已有 3 项辅助测试，共 8 项通过：验证三个输出布局、含空格/中文/Windows 路径的参数原样保留、技能完整写出、配置不被修改、拒绝覆盖目录/符号链接、拒绝丢弃认证或运输字段、错误结构化，以及打包不执行 MCP 命令。另执行 skill 校验、全部 Python 语法检查与本地 Markdown 资源链接检查。

**本次没有在 Cursor 或 Claude Code 实际加载服务器、调用模型或验证侧栏后端。** 自动化测试验证的是生成器行为；客户端配置格式的文档核对与实际客户端端到端验收分开记录。未知 agent 的中性包仍需按其规范转译。

## WorkBuddy 流程与生成器（2026-10-18）

对照 WorkBuddy 官方技能上传、自定义连接器及开放平台 MCP 规范补充独立接入说明和提示词，新增 `--client workbuddy`。输出为本地接入材料：单 server 的 `mcp.json`、单文件软件操作 skill、可上传的 `operation-skill.zip` 与说明。它不写用户配置、不执行 MCP server，也不生成冒充已发布连接器的元数据。

9 项 Python 辅助测试通过（此前 8 项 + 1 项 WorkBuddy CLI/ZIP 行为测试）。原有参数保持测试同时覆盖新增第四种布局；新增测试实际调用生成器，读取 ZIP 校验文件名/内容、验证命令未被执行且未创建猜测的客户端配置目录。另执行 skill 校验、Python/JSON 语法和本地资源链接检查。未修改 Rust 补丁，未重跑参考实现的 289 项 UI 测试。

WorkBuddy 客户端加载、握手及真实文档操作均未在本次验证；本仓库也未实现 WorkBuddy 内嵌聊天运行时或申请市场发布。流程依据链接在 [WorkBuddy 参考](../skills/desktop-mcp-copilot/references/workbuddy.md)，格式核对不等于端到端兼容证明。

## 尚未证明

未在每款 ArtCraft 相关软件或每种操作系统中实现同等侧栏；未验证所有 agent 的配置格式；普通 MCP JSON 不强制只读；外部只读摘要不一定暴露稳定文档 UID。图片采样不是实时屏幕监视。不能把语义评估、模板生成或工具枚举描述成完整的写操作验收。

不发布个人原始运行日志、聊天、图纸、账号、系统配置和大二进制。公开验证只保留命令、计数和不含个人数据的摘要。
