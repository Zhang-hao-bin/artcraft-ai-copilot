# 从一次定制到可交接的工程

这个项目把实际操作分成可以单独验证的阶段：

1. 检查正在使用的窗口与未保存文档，确认控制端口的协议。
2. 用 MCP 包装连接该窗口；初始化并列工具，实际只读核对文档。
3. 为软件编写操作 skill，封装元数据和 MCP 配置，避免全局与插件重复加载。
4. 在可修改源码的 GUI 增加 app-server 侧栏，工具回调落到应用本身的命令。
5. 完善中文输入、启动/错误/停止状态、模型与思考强度，以及收起后的可见入口。
6. 把文档 UID 和会话状态分开管理，新文件隔离、新对话新增、旧记录可切回。
7. 保存与恢复有界历史；切换、停止、异步完成时检查目标身份，防止操作串到另一张图纸。
8. 原生能力不足时使用明确独立的后端，例如 FreeCAD；输出真实文件和几何验证，保留能力边界。
9. 保存源码补丁，以固定上游提交复现；升级时独立合并、检查、构建和校验，安装与提醒分开。
10. 导出完整 skill 和插件模板，移除个人配置、聊天、账号、机器路径与大构建产物，形成这个仓库。

参考实现的源码补丁约 115 KB，包含新增 Rust 模块和必要的上游文件修改，而不是整个 CADCraft fork。完整构建保留上游 Git 来源和许可。仓库的文档描述已完成的 CADCraft 集成，不把迁移指南当作其他软件已经集成成功的证明。
