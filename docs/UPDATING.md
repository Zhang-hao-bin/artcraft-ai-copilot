# 上游版本维护

本仓库固定补丁基线是 CADCraft v0.7.0。更新时先保存当前定制改动为补丁，在独立 clone 中获取稳定标签，再三方合并。出现冲突或检查失败时停止，旧版继续保留。不要对用户的原工作目录执行 reset。

安装器生成的版本维护入口为：

```bash
~/.local/share/artcraft-ai-copilot/launchers/artcraft-cadcraft-update check
```

也支持 prepare、build、install、update、rollback 和 status。update 组合合并、检查、构建和安装；因此只在用户决定更新后运行。定期检查只能执行 check，发现新版本再提醒用户。脚本不创建定时任务，也不会自动杀掉运行窗口。

构建通过后核对源码指纹和程序 SHA256。安装必须先保存并退出，使用窗口锁和进程检查防止覆盖运行实例；备份旧程序和设置，再原子替换程序。回退旧程序不会恢复旧设置来覆盖更新后新增的聊天。

当前维护脚本更新的是 GUI Copilot 程序。MCP CLI 在初次构建/安装时来自同一上游版本；后续跨版本升级应重新验证其协议兼容性，必要时通过完整构建流程更新 CLI。不能据 GUI 的构建通过推断旧桥接器和所有第三方客户端仍兼容。

源码和版本记录位置由本机生成的安装配置决定，不能把别人的路径、PID、代理或账号复制进你的安装。未来上游 API 或 Rust 工具链变化可能需要人工适配。检查失败应作为失败报告，不能当作没有新版本。
