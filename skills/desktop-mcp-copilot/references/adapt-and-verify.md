# 迁移到其他软件与验收

## 建立一份适配记录

在新项目中记录下列真实值，后续交接引用该记录，不复制 CADCraft 路径或端口：

| 项目 | 必须确认的内容 |
|---|---|
| 软件和环境 | 名称、版本、OS、可执行文件、运行中的窗口 |
| 文档身份 | 文档列表、稳定 UID、保存路径、未保存状态、选择/视图 |
| 控制接口 | 已有 MCP/API/SDK/CLI/源码，运输协议、实际地址和认证 |
| 写操作 | 命令 schema、单位、撤销、保存、UI 线程要求 |
| UI 扩展 | 官方扩展面板或源码可修改能力；不可内嵌时的替代交付 |
| Agent/客户端/运行时 | 制作 agent、接收客户端版本/配置/重载方式、侧栏后端及真实支持能力 |
| 验证任务 | 一个有可量化结果的测试文件、只读状态、失败/取消情形 |

比如图像软件需读图层/画布/选择、修改后验证图层和像素；办公软件需读工作簿/文档身份、单元格或段落、撤销和保存；CAD 需对象几何/坐标系/单位/尺寸标注。软件名只是路由提示，不能推定有现成 MCP 或支持哪个 OS。

有软件源码时遵循现有语言和架构；有官方插件 SDK 时优先扩展，不为了这个技能重写软件。有连接但没有 UI 扩展能力时交付外部 agent 接入，侧栏需求另说明实现方式和限制。

## 渐进交付

1. **只读连通**：握手、工具目录、目标窗口/活动文档身份。
2. **真实操作**：在新的测试文档创建一个简单对象，读取结果验证数值/属性，再检查撤销与保存。
3. **插件封装**：配置、操作 skill、元数据、依赖与客户端导入；验证无重复工具。
4. **内嵌侧栏**：UI、已选运行时适配器、真实工具调用、视图和支持的模型选项。
5. **文档内多会话**：按稳定身份隔离状态、历史切换、持久化和取消守卫。

以用户需求决定停在哪层，不为只读接入增加不必要的后台服务或内嵌改造。

## 行为验证清单

| 场景 | 可观察的正确结果 |
|---|---|
| 只有 MCP 配置写入 | 报告已配置，尚未证明运行 |
| 握手和 tools/list | 协议正常，尚未证明目标文档或写能力 |
| 读取两个不同文件 | 正确文档 UID、路径/标题和状态 |
| 在测试文档执行命令 | 精确对象/数值正确，真实命令被调用 |
| 中文输入及显示 | 组合输入可提交，切换输入法和焦点正常 |
| 启动/自动连接/失败重试 | 连接状态可见，错误后仍能继续输入 |
| 模型与强度变化 | 合法选项，下一轮实际使用新设置，恢复默认不残留旧覆写 |
| 收起和重开 | 可见入口与快捷键有效，记录及 draft 未丢失 |
| 新文件 | 一段空白会话，不继承其他文件消息或 artifact |
| 文件切换/关闭前一标签 | 仍按 UID 恢复各文件各会话，不按变化的索引串位 |
| 新对话 | 原会话留在列表，新增会话独立 thread/草稿/记录 |
| 切回旧会话 | 旧消息、draft、模型设置及输出入口恢复 |
| 保存文件后重启 | 恢复正确文件的列表和 active ID，不假称原进程/thread 正在运行 |
| 旧格式升级 | 单会话迁移成会话 1，先备份，无法确定归属的混合记录保留为独立备份 |
| 另存为 | 旧新路径历史按预定策略独立，不覆盖其他文件记录 |
| 停止/切换中的迟到工具 | 不修改新文档，不打开旧请求生成的窗口，不重新进入 busy |
| 非法参数、索引、超时 | 错误可理解，已有文档和聊天保留，应用不崩溃 |
| 能力超出软件支持 | 如实说明，不能把截图/线框/模板冒充实际结果 |

用界面截图检查布局；无法取得窗口帧时记录限制，可用真实 UI 控件的自动化点击与软件状态断言补充。仅做 headless 文档 render 不能证明侧栏控件正常。

## 有用的故障定位

- **工具不出现**：核对客户端加载位置、JSON/TOML、插件安装状态及重载时机；别只看 `Added server`。
- **能列工具但不能操作当前窗口**：检查实例、端口、UI/后台模式和文档 UID，重新只读确认。
- **模型服务启动不了**：核对可执行文件、初始化返回、登录与进程网络环境；不要泄露认证文件。
- **菜单有侧栏却无法启动聊天**：分别检查显示状态、连接按钮/状态、服务初始化和发送路径。
- **中文乱码/输入法不切换**：区分字体缺字与 IME composition/focus；识别本机输入法及 UI 框架后修复。
- **新对话删除旧消息**：检查是否仍在调用 reset；改成新增 ID + 会话池 + 列表，并迁移旧持久化数据。
- **异步工具画错文件**：检查请求捕获的目标 UID/会话 ID、取消标记和 generation；不要执行时只读取当前标签。
